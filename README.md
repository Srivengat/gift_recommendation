🎁 AI Gift Recommendation System

📖 About the Project

The AI Gift Recommendation System is a full-stack web application developed as part of my Full Stack Developer Internship at HTC Global Services. The project helps users discover personalized gift recommendations through an interactive chat-based interface.
Users provide details such as the recipient, occasion, interests, preferred category, and budget. The system processes these preferences using AI-assisted filtering and recommends the most relevant gifts from the database, providing a simple and personalized gifting experience.

✨ Features

- 🤖 AI-assisted gift recommendation engine
- 💬 Interactive chat-based interface
- 🎯 Personalized recommendations based on user preferences
- 💰 Budget-based gift filtering
- ⚡ REST APIs developed using FastAPI
- 🗄️ MySQL database integration
- 🛒 Demo checkout page

🛠️ Tech Stack
Frontend: React.js, Vite, HTML, CSS, JavaScript
Backend: Python, FastAPI, SQLAlchemy, Pydantic
Database: MySQL
AI:Ollama (Phi-3)
